DIVA CARTOUCHE ASSISTANT
========================

Installation simple
-------------------
1. Decompressez le ZIP dans un dossier.
2. Double-cliquez sur Install-Diva.bat.
3. Un raccourci est ajoute automatiquement au vrai Bureau Windows.

L'installation ne demande pas de droits administrateur et ne suppose pas que le
Bureau s'appelle Desktop. Le dossier racine est fourni par le schema prive de
votre organisation.

Prerequis
---------
- Windows 10 ou Windows 11 en 64 bits.
- Microsoft Word version bureau pour creer les documents a partir des modeles.

Utilisation
-----------
- Lancez Diva depuis le raccourci.
- Choisissez le modele, le type, le domaine et remplissez les champs demandes.
- Cliquez sur Creer et ouvrir le document.
- Le DOCX et le PDF sont crees dans le dossier exact du document; Word et ce
  dossier s'ouvrent automatiquement.

PDF automatique
---------------
Diva reste dans la zone de notification Windows apres la creation. Quand le
DOCX est enregistre dans Word, le PDF de meme nom est actualise automatiquement.

Le guide complet est inclus dans le fichier Diva-cartouche-assistant-guide.pdf.
